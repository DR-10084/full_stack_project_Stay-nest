# StayNest 🏡

A full-stack accommodation listing web application built from scratch using Node.js, Express, MongoDB, Mongoose, and EJS.

## Features

- Create, Read, Update, and Delete listings (CRUD)
- MongoDB database integration
- Dynamic EJS pages with reusable layouts
- Bootstrap responsive UI
- Default image handling
- RESTful routing with method-override

## Tech Stack

- **Frontend:** HTML, CSS, Bootstrap, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **ODM:** Mongoose

## Key Learnings

- Backend routing and CRUD operations
- Database integration using Mongoose
- EJS templating and reusable layouts
- Form handling and debugging
- MVC project structure

## Run Locally

```bash
npm install
node init/index.js
nodemon app.js
```

Open: `http://localhost:8080/listings`
